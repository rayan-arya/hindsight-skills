# resolve-outcomes

## Description

Grades a single take against public evidence and returns an outcome verdict.

## Input

`ResolveOutcomesInput` from `@hindsight/types`:

```json
{ "take": "Take" }
```

## Output

`ResolveOutcomesOutput` from `@hindsight/types`:

```json
{ "outcome": "Outcome" }
```

## Invocation

POST /skills/resolve-outcomes
